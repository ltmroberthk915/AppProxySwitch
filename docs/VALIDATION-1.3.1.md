# AppProxySwitch 1.3.1 验证记录

日期：2026-10-13。

Debug 和 Release 构建成功，`APS_TEST_HOOKS=OFF`。Release 全套 unit 和
integration **27/27 通过**，耗时 291.18 秒。

引擎回归 **122 用例、1776 断言通过**。新增场景覆盖共享节点的独立服务
策略组、该组的监测和恢复目标、嵌套组解析、未引用偏好、全局和旧控制器
兼容，以及无效选择链的错误报告。

Relay 检查覆盖完整与截断的 HTTP 正文、超过单次发送预算的读取空闲间隔、
双向半关闭、EOF 来源日志及不记录响应内容。只读诊断检查覆盖缺少进程
路径时的 socket 归属、其他进程和其他代理端口排除、地址核对、无效元数据
容错及脱敏输出。两项内核缓存测试等待路由快照就绪，原功能断言保留。

Debug 首轮其余 26 组通过；修正两项缓存测试的等待条件后，受影响的引擎
和诊断目标 2/2 通过，覆盖全部 27 个测试目标。

本地检查使用隔离缓存、模拟包设备和本机模拟服务。真实驱动 E2E 留给
GitHub Windows CI；本地没有启动第二个引擎接管通信。TCP 正常关闭和
控制器延迟测试不能证明目标业务流完整，远端服务错误需独立分析。

发布包主程序使用通过上述检查的 Release 文件。发布目录中的产品说明
来自本仓库；下载文件的 SHA256 见发布页 `SHA256SUMS.txt`。
