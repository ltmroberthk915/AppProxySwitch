## 可达性边界

受控现场验证复现：应用持有旧 IP、APS 没有对应 DNS 观察记录时，SOCKS CONNECT
使用 IP 而非可见 SNI 域名，导航超时；同域名通过 SOCKS DOMAIN 能完成证书验证
并得到 HTTP 响应。新的回归覆盖该缺口，没有恢复或重放用户令牌/Cookie。

这不证明全部现场异常都有同一原因，也不证明鉴权 Codex 会话或长响应已恢复。
上游 TLS 提前关闭、Cloudflare 挑战及其他远端错误需要分别核验。安装并启用名单
后仍需实际会话验收；在此之前保留应急通道。
