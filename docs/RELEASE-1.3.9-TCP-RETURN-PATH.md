# APS 1.3.9：TCP 回程注入方向修复候选

此前，代理回包在还原远端服务器地址后仍以出站方向注入。WinDivert 发送时忽略
`Loopback` 标志，单独设置该标志不能把回包变成入站流量。这条路径可能与其他
Windows 网络过滤驱动发生兼容问题，表现为本地握手反复重传，新连接无法建立。

本版在首次 SYN 时为每条连接保存原始接口信息和环回属性。外网回程明确使用
入站方向及对应接口；原本机环回连接继续走出站路径。SYN-ACK、数据、FIN、RST
共用该规则，原目标地址、TCP 序号、正文和校验和保持正确。

主动断开时生成的 RST 同样使用所属连接的信息，不再跨线程读取“最后收到的包”，
避免混入其他网卡或连接的状态。正向规则、出口选择、订阅与第三方配置不作调整。

新增隔离回归覆盖外网回程、握手重传、多网卡交错、本机环回、普通直通和主动断开。
旧代码在这 5 个用例的 244 个断言中失败 64 项，修复后全部通过。
这证明代码层面的方向与接口缺陷已修正，不等于所有加速器组合已完成实机验收。

安装候选前请先正常停止截流，并从托盘退出旧版 APS。保留可用的独立通信通道，
安装后再核验实际应用的新连接与长连接；仅编译或打包不会更新运行中的引擎。

API 依据：[WinDivert 2.2.2 文档的 WinDivertSend 说明](https://github.com/basil00/WinDivert/blob/v2.2.2/doc/windivert.html)。
