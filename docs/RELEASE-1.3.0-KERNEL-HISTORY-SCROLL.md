# AppProxySwitch 1.3.0：内核历史与节点滚动

未启动内核只显示进程名称，例如 `verge-mihomo.exe`。同名历史记录合并为一行；已有在线实例时，不额外展示该名称的历史离线行。当前已选或被规则明确绑定的离线出口仍保留，方便识别连接状态。

运行中的内核显示重新发现的当前端口。同名的多个在线实例各有自己的行和连接按钮。手动填写的代理端口及手动出口保持原有行为。

自动发现缓存升级为 v3，不再保存独立的 SOCKS/API TCP 端口字段。旧缓存会在新版首次完成扫描时自动迁移，即使所有内核都未启动。保留名称、稳定出口编号、配置目录和必要的控制器识别信息；已有密钥和启动信息继续使用 DPAPI。当前监听端口由内核进程重新验证，离线缓存不会作为可用出口。

节点区域增加独立的纵向滚动条，支持拖动和鼠标滚轮。节点状态、地区/类型/策略组及测试详情根据文字长度自动换行并调整高度；区域超出可视高度时内部滚动。规则表、活动连接表与页面滚动仍可分别使用。

本版包含 1.2.14 的空闲接收看门狗修复、内核模式显示和只读业务路由诊断。没有新增自动修改 SakuraCat/Verge 模式、TUN 或系统代理的行为。

升级时先正常停止并退出 APS，再安装新版并重新启动引擎。程序包的生成不会替换运行中的 APS。
